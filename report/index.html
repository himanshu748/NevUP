Verification

Run these commands from the repository root before shipping changes:

python -m compileall app tests eval.py profiler.py
python -m pytest
python eval.py

eval.py creates eval_report.json and eval_report.html as local artifacts. They are ignored by git because they can be regenerated from nevup_seed_dataset.json.
